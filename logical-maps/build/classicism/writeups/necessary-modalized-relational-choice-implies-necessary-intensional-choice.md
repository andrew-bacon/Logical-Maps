# □Modalized Relational Choice ⇒ □Intensional Choice

<p class='cert'>Result — Source: Misc., Lean `Classicism.Map.necessary_modalized_relational_choice_implies_necessary_intensional_choice`; produced by Claude Opus 5.5 (Anthropic), 11 October 2026, from a suggestion of Cian Dorr; recorded by Claude Opus 5.5 (Anthropic), 11 October 2026.</p>

## Premises

- **□Modalized Relational Choice.** Necessarily, every necessarily serial relation is entailed by a necessarily functional relation.

## Conclusion

- **□Intensional Choice.** Necessarily, if a property is necessarily instantiated, then some property entailing it is necessarily uniquely instantiated.

## Proof

The argument of [[modalized-relational-choice-implies-intensional-choice]] is a C-proof of each instance of Intensional Choice from an instance of Modalized Relational Choice. Necessitate it and apply K.
